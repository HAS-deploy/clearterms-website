Privacy Policy

Last updated: 2026-04-17.

TermPlainly is a document explainer: you upload a document, we return a plain-English summary. This policy describes exactly what happens to that document and anything else we can see.

Who we are

TermPlainly is published by HAS Deploy. Support: tony@medbillresolve.com.

Data we collect about you

  • A random install ID. On first launch, the app creates an anonymous UUID and stores it in iOS preferences. That ID identifies this install to our backend so credits can be tracked per device. It is not linked to your Apple ID, name, email, IP address, or any advertising identifier.
  • No account. We do not ask for, store, or use an email address, phone number, or profile picture.
  • No analytics SDK, no ad SDK.

Data we receive from your document

When you tap "Analyze" the app:

  1. Uploads the raw document to our server over HTTPS, into an Amazon S3 bucket encrypted at rest with AES-256.
  2. Our server extracts the text of the document and sends that text to Anthropic's Claude API for analysis.
  3. The analysis text is stored in our Amazon DynamoDB database so you can re-open it later.
  4. The raw uploaded file is automatically deleted from S3 within 24 hours by an S3 Lifecycle rule. The extracted text is not separately retained.

What Anthropic does with your document text

Per Anthropic's published policies at the time this policy was last updated, data submitted through their API is not used to train their models. See Anthropic's Privacy Policy for the latest. If that changes, we will update this page.

Purchases

In-app purchases are processed by Apple via StoreKit. We see a transaction ID and product ID; we never see your name, address, or payment method.

What we share

Nothing, except:

  • Document text → Anthropic's Claude API (for analysis).
  • Purchase receipts → Apple's StoreKit verifyReceipt endpoint (to confirm credit purchases).

We do not sell, rent, or trade data. We do not run third-party analytics.

Children

TermPlainly is rated 17+ and is not directed at children under 13.

Your choices

  • Uninstall the app to delete the local install ID and any cached analysis.
  • Email tony@medbillresolve.com to ask us to delete any stored analyses associated with a specific install ID (include that ID in the message).

Security

TLS 1.2+ in transit. AES-256 at rest in S3. IAM least-privilege on all server code. No root-user access keys are embedded in the app.

Changes

We will update this page with a new "Last updated" date when anything material changes.
